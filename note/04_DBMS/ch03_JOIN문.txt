ch02_JOIN문
1. CROSSJOIN
	=> 단순하게 기어붙임. FROM절에 테이블을 여러개 넣음. 의미는 존재하지 않는 방식
2. EQUI JOIN 
	=> 원하는 특정 필드의 값과 조건이 동일한 경우만 JOIN
	LEFT JOIN 형태와 동일하게 사용
3. NON-EQUI JOIN 
	=> 공통된 필드가 없고 범위 형태로 존재할 때, 범위에 맞는 경우 값만 JOIN
	EX) SELECT *  FROM EMP, SALGRADE WHERE SAL BETWEEN LOSAL AND HISAL AND ENAME = 'SCOTT';
4. SELF JOIN 
	=> 같은 데이터를 붙여서 원하는 정보를 검색하는 방법. DEMO 데이터의 경우
	      MGR과 EMPNO가 같은 경우를 출력하기 위해서 활용.
	EX) SELECT E.ENAME, E.JOB FROM EMP E, EMP M WHERE E.MGR = M.EMPNO AND M.ENAME='KING';
5. OUTER JOIN
	데이터가 NULL이 있을 때 보여주기 위해 '비교값'에 (+)를 추가하면 사용 가능. 
	=> 비교값이 원본의 값을 모두 수용하지 못하는 경우 활용
	예시) 
		-- 배제된 행을 결과에 포함 시킬경우 (+)기호를 정보가 부족한 필드명 뒤에 덧붙임
	SELECT E.ENAME || ' 의 상사는 ' || NVL(M.ENAME,'없음')|| '이다'
   		 FROM EMP E, EMP M
    		WHERE E.MGR = M.EMPNO(+); -- MGR에 NULL이 있고 EMPNO에는 NULL이 없음
