ch07_python과 db 연동하기

- sqlite3 => 프로토 타입용, 컴퓨터에서 sql developer 처럼 사용하려면 db brower for sqlite 필요
0. 파일 I/O와 다르게 단방향 통신이 아니라 양방향 통신이 가능하다(요청과 결과 반환 과정)
1. DB 연결 객체 conn = sqlite3.connect(연결할 파일.db)
	1.1 커서 객체 cursor = conn.cursor()
	1.2 커서 객체를 통해 sql문 전송 : cursor.execute(''' sql구문 with out ' ''') => 트랜잭션에 명령어 덩어리 만듬
	1.3 sql문 insert, update, delete 성공 시 print(cursor.rowcount)를 통해 정수 값 체크
	1.4 conn.commit()을 실행해야 내용이 전송됨
	1.5 select구문 전송 후 받을 때는 fetchone, fetchall, fetchmany(n)을 통해 받음.
	     헤더를 받으려면 cursor.description 사용 => 이중 튜플로 반환.
		#  cursor.fetchone() : 결과를 한 행만 받을 때 (튜플형태 : ('홍길동', 21, 'h@h.com') ) 
		# fetch는 => 한 번 작동하면 다음 데이터로 커서가 이동하여 작동하므로 주의
		# 결과만 보면 리스트의 pop과 동일
		#  cursor.fetchall() : 결과를 모두 받을 때 [리스트 ('홍길동', 21, 'h@h.com'), ('김길동', 31, 'k@k.com')]
		#  cursor.fetchmany(n) : 결과를 n행 받을 때 [리스트 ('홍길동', 21, 'h@h.com'), ('김길동', 31, 'k@k.com')]
--- 볼 일 끝나면 .close해주기 (cursor, conn 모두)
