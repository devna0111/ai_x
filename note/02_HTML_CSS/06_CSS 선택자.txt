CSS 선택자 교안 확인

0. 태그 선택자 :
CSS 설정을 위한 각 태그를 활용해 스타일 설정 가능

1. 전체 선택자 :
<style> *{} </style> : 최초 환경 초기화
	★★ 메뉴 nav 설정 ★★★★★★★★★★★★★★★★★★★★★★★★★★★★
                nav ul { /* 수평으로 하고픈태그의 부모 */
                        overflow : hidden ; /* 자식태그(li)를 수평으로 하겠다(정상적인 float 전제 조건) */
                }
                nav ul li { /* 수평으로 할 태그 */
                            float : left ; /* 좌/우로 태그를 띄워서 붙인다*/

2.  <li class = "menu1 odd">menu 1</li> : class 설정 : menu1 이며 odd (뛰어쓰기 X 다중 부여)
	class style 접근 시 => .class이름
	id style 접근 시 => #id 이름

3. 혼합선택자 => 여러 선택자를 섞어가면서 활용한다
	=> 항상 주의할 것 : 태그선택자 하위 태그가 아니라 class,id라면 뛰어쓰기를 하지 않는다.
	#wrap #contents li.odd
	#wrap #contents li .odd  => 오답
	div#header
	div #header => 오답

4. 속성선택자 ★★★★★★★★★★★★★★
	반드시 태그와 함께 사용
	input[type='password'] {} input 중 type이 password인 경우 {}속성을 부여해라
	input[type^='te'] {} input 중 type이 te로 시작하는 경우 {}속성을 부여해라
	input[name$='me] input 중 name속성이 me로 끝나는 경우 {}속성을 부여해라
	img[alt] img태그 중에서 alt속성이 있는 경우 {}속성을 부여해라

	** 속성값 설정으로 배경에 그림넣기 : {background : url(주소) no-repeat ; }

5. 후손자손선택자
	1대 차이 자손(자식) (div > p {} 형태로 직할일 시 {}속성을 부여할 때 활용)
	모든 하위 선택자 후손

6. 동위선택자
	h3 ~ div : h3 이후 형제급 이하 전부
	h3 + div : h3 바로 다음 형제 하나의 모든(이하) 친구들

7. 반응선택자
	원하는 태그:hover {} 
		-> 원하는 태그에 마우스를 올려두면 {}속성을 부여

8. 상태선택자
	input창에서 focus에 따른 반응

	태그속성 부여 :
	1. 불능 : disabled ='disabled'
	2. 읽기 전용 : readonly="readonly"

	CSS속성 부여 :
	1. input:focus {} => 작성이 끝난
	2. input:enabled {} => 커서가 올라간
	3.input:disabled{} => disabled 속성을 부여한
	4.input:read-only{} => 읽기 전용 속성(3번 disabled 포함)

9. 구조선택자
	li:nth-child(조건식) {} : 조건에 맞는 부분에 {}속성을 부여
	li:first-child {} : 첫번째 자식에 {}속성부여
	li:last-child {} : 마지막 자식에 {}속성부여
	★★★★★ 선택자 양식을 통일해야 내가 원하는 결과를 유추하기 쉽다.
	ex) div#nav 와 #nav를 동시에 사용하면 결과를 유도하지 못함...혼합선택자에 따라? 

10. 문자선택자
	li:first-child::first-line, first-letter 를 통해 지정이 가능

11. 링크부정선택자
	a:after{} a 뒤에 {}속성 부여
	링크 선택자 => 기존 그냥 네이버 => 네이버-HTTP://WWW.NAVER.COM
                #contents ul li a:after{
                        content:'-' attr(href); }
	부정선택자 => class가  shop인 것만 제외하고 속성부여 ** 
                #contents li:not(.shop){/* 부정선택자 */
                                       background-color : yellow; }
