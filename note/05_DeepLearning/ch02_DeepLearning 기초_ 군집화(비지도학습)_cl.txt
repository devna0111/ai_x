ch02_DeepLearning 기초_ 군집화(비지도학습)_clustering
군집화는 예측하는 기능이 아니라 정보를 제공했을 때 분류만 하는 기능

#1. 데이터 생성 : output이 없는 input값만 지정
#2. 군집화 로직 : 데이터 속 랜덤 분류값을 넣어서 거리를 계산, 가까운 쪽에 포함되도록 그룹핑
		        위 작업 후 새로운 그룹에서 중앙값을 새로운 분류값으로 사용하여 반복작업.
		        이렇게 여러 차례 반복하게 되면 정확하지는 않더라도 약 5:5의 비율의 군집화 작업 완료
# 3. 전체 코드(for문 이용)
- data 생성
- 랜덤포인트 2지점
- for문 활용
	- 랜덤포인트 2지점 기준으로 group화 => group1, group2
	- 랜덤포인트 이동(group1 중간점, group2 중간점)
- 데이터 체크

# 4. api를 이용한 군집화 => sklearn의 cluster 중 KMeans 모델 활용
data = np.array(data)
from sklearn.cluster import KMeans
# 모델 객체 생성
model = KMeans(n_clusters=2, # 2개 그룹으로 나눠라
              init = 'random', # 초기 중심점 랜덤하게
              n_init = 10, # 10번 반복 실행
              )
model.fit(data) # 모델 학습
# 중심점
model.cluster_centers_
