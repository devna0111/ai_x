IRIS데이터 기반 기본적인 레이어에서 다양한 방법으로 모델을 설계

## 함수형 API 이용
=> 좀 더 복잡한 모델 설계가 가능하다
1. 다중 입력 및 출력 처리 가능

여러 개의 입력과 출력을 동시에 다룰 수 있어 복잡한 모델을 설계하는 데 적합합니다.

2. 비순차적 구조 지원

순환 네트워크, 스킵 연결(Residual Connections), 다양한 병렬 경로를 구현할 때 필요합니다.

3. 재사용성 및 모듈화

여러 모델 또는 계층을 재사용할 수 있어 유지보수와 확장이 용이합니다.

4. 더 깊고 복잡한 모델 설계 가능

딥러닝 연구에서 자주 사용되는 고급 아키텍처(ResNet, Inception 등)를 구축할 수 있습니다.

병렬처리 : 속도를 높이기 위해서 
	병렬처리는 여러 개의 신경망 레이어를 동시에 학습시키는 기법
	다양한 특성을 동시에 학습할 수 있어 모델 성능을 향상시킬 수 있습
	from tensorflow.keras.layers import concatenate # 병렬처리시

레지듀얼블록(Residual Block) : 모델의 성능을 높이려고 -> 자연어처리, 이미지 처리
	잔차 연결(residual connection)을 의미하며, 깊은 신경망에서 정보 손실을 줄이고 학습을 안정화
	기울기 소실(gradient vanishing) 문제를 완화
	역전파(Backpropagation) 과정에서 기울기(Gradient)가 점점 작아져서 거의 0에 가까워지는 현상
	초기 층(입력층에 가까운 층)의 가중치가 제대로 학습되지 않는 문제
	from tensorflow.keras.layers import Dense, Input, add # add :레지듀얼블록
