ch01_DeepLearning 기초
머신러닝은 크게 지도학습과 비지도 학습으로 나눠진다. 
지도 학습의 경우 분류, 회귀 모델이 대표적이고 
비지도 학습의 경우는 군집(clustering) 모델이 있다.

회귀는 단일 값을 반환하고 => 정답을 뽑아내야 하는 수학 문제에 용이
분류는 특징을 수치화 해서 각 분류의 대표적인 특성을 따라서 분류와 신뢰도를 나타낸다.
=> 위 두 모델은 라벨링을 통해 input과 output을 주어야 한다 

군집의 경우 1집단, 2집단 등 집단을 데이터셋의 특징에 따라 분류구성한다.
=> 비지도 학습으로 스스로 카테고리를 나눠낸다. 자율학습

학습은 회귀 => 분류 => 군집 3단계로 걸쳐 실시

머신러닝의 기본 프로그래밍 프로세스
```
1. 데이터 확보 및 생성 
2. 데이터 전처리 : 
    스케일 조정
    훈련데이터(학습데이터셋) + 검증용데이터셋 + 테스트데이터셋 분할
3. 모델 구성
4. 모델 학습 과정 설정
5. 모델 학습
6. 모델 평가(시험 데이터 셋(테스트 데이터 셋) 활용)
    <모델 저장>
7. 모델 사용(입력 값이 주어지면 예측 값 받기)

- 스케일 조정 => Local Minima에 갖춰있을 수도 있어서 체크가 필요 => 우리가 찾는 것은 Global Minima
- normalization(정규화) : 데이터를 0 ~ 1 로 조정
                      X - Xmin
    normalization = ---------------------------------------------
                      Xmax - Xmin
                  * 위의 식을 써도 되지만 라이브러리를 씀(sklearn.preprocessing.MinMaxScaler 이용)
                  
- standardization(표준화) : 평균 0, 표준편차 1로 조정
                        X - Xmean(평균)
    standardization = ------------------------------------------------ 
                        Xstd(표준편차)
                  * 위의 식을 써도 되지만 라이브러리를 씀(sklearn.preprocessing.StandardScaler 이용)

## 데이터가 2차원 np.array여야만 가능하다
# 라이브러리 쓰고 정규화 (MinMaxScaler 이용)
from sklearn.preprocessing import MinMaxScaler
x_data = np.array([1,2,5,8,10]).reshape(-1,1)
y_data = np.array([3,15,68,80,95]).reshape(-1,1)
# np.column_stack([x_data,y_data])
scaler_x = MinMaxScaler() # x데이터를 정규화 시킬 객체(2차원만 가능)
scaler_y = MinMaxScaler() # y데이터를 정규화 시킬 객체
# scaler_x.fit(x_data)
# scaled_x_data = scaler_x.transform(x_data)
scaled_x_data = scaler_x.fit_transform(x_data)
scaled_y_data = scaler_y.fit_transform(y_data)
np.column_stack([x_data,y_data,scaled_x_data,scaled_y_data])
