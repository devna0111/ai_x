1. 🛠 딥러닝에서 과적합 방지 방법 7가지
전략	설명
1. 조기 종료 (EarlyStopping)	검증 성능이 더 이상 개선되지 않으면 학습을 조기 종료
2. 드롭아웃 (Dropout)	학습 중 일부 뉴런을 랜덤으로 꺼서 과적합 방지 => 레이어 추가
3. 정규화 (L1/L2 Regularization)	큰 가중치를 억제하여 일반화 성능 향상
4. 데이터 증강 (Data Augmentation)	학습 데이터를 변형해 다양성 확보 (주로 이미지/텍스트)
5. 모델 구조 단순화	층 수나 노드 수 줄이기, 과도한 복잡도 제한
6. 배치 정규화 (BatchNormalization)	학습 안정화 및 일반화에 도움
7. 학습 데이터 증가	데이터가 많을수록 과적합 위험 ↓ (가능하면 최고의 방법)

2. 드롭아웃 사용 방안
from tensorflow.keras.layers import Dropout
model = Sequential()
model.add(Input(shape=(8,)))
model.add(Dense(units=32, activation = 'relu'))
model.add(Dropout(0.2)) # 과적합을 해결하고자 파라미터를 두루뭉실하게 넘김, 20퍼센트는 drop => 0.49까지 실용성
model.add(Dense(units=64, activation = 'relu'))
model.add(Dense(units=16, activation = 'relu'))
model.add(Dense(units=8, activation = 'relu'))
model.add(Dense(units=2, activation = 'softmax'))
model.summary()
