| 함수 이름       | 설명                                                                       |
| ----------- | ------------------------------------------------------------------------ |
| `'relu'`    | ReLU(Rectified Linear Unit): 0 이하이면 0, 초과면 그대로 출력. 학습 속도 빠르고 일반적으로 잘 작동. |
| `'sigmoid'` | 시그모이드: 출력 범위 (0, 1). 이진 분류 출력층에 주로 사용.                                   |
| `'tanh'`    | 하이퍼볼릭 탄젠트: 출력 범위 (-1, 1). 시그모이드보다 중심이 0이라 학습이 더 잘 됨.                     |
| `'softmax'` | 다중 클래스 분류에서 출력층에 사용. 출력값을 확률로 정규화 (합이 1).                                |
| `'linear'`  | 선형 함수: 아무 것도 적용하지 않음 (`f(x) = x`). 회귀 문제의 출력층에 주로 사용.                    |





| 함수 이름            | 설명                                                                         |
| ---------------- | -------------------------------------------------------------------------- |
| `'elu'`          | Exponential Linear Unit: ReLU의 확장으로, 음수 입력도 완전히 죽지 않도록 함.                  |
| `'selu'`         | Scaled Exponential Linear Unit: 내부 표준화를 지원하며, 특정 조건에서 self-normalizing 효과. |
| `'softplus'`     | 부드러운 ReLU. 항상 양수이며 미분 가능.                                                  |
| `'softsign'`     | 입력을 크기에 따라 부드럽게 제한.                                                        |
| `'swish'`        | 최근 Google이 제안한 함수. `x * sigmoid(x)` 형태. 성능이 좋은 경우도 있음.                     |
| `'gelu'`         | Gaussian Error Linear Unit. BERT 등 최신 모델에서 사용됨.                            |
| `'hard_sigmoid'` | 시그모이드 근사로 계산량 줄인 버전.                                                       |
| `'exponential'`  | `f(x) = exp(x)`. 특수한 경우에 사용.                                               |
