1. 익명 함수
	lambda함수랑 비슷한 개념..?
	let varname = function(매개변수){구문}; 로 정의
	=> 절차지향적 수행방식
	=> 파이썬과 동일한 수행방식으로 작동
		** 차이점으로, 수정할 때 화살표 함수를 사용할 수 있다. funcName = (매개변수) => {구문}

2. 화살표함수 ★★★★★
	function () => {...} 기본 형태 : 매개변수가 하나이거나 ...이 한 줄의 코드라면 괄호는 생략이 가능하다.
	=> 주 사용처 : arr.forEach((data,idx) => console.log(data,idx))

3. 선언적 함수 : 이름이 있는 함수
	★★★★ 선언적 함수 정의 위에서도 호출이 가능 => 인터프리터의 해석 우선순위가 함수선언문이 먼저, 우선 '함수 선언 후'
		     함수를 호출해서 가능함
	파이썬과는 다르게 매개변수의 기본값을 주지 않아도 에러가 나지 않으며 필요 매개변수보다 많이 부여하면 과적은 무시
	=> undefined 혹은 NaN을 반환함

4. 가변인자함수
	일반 함수표현식에서 사용 가능하며 화살표 함수에서는 사용 불가
	=> arguments를 함수 실행구문 속에서 활용가능 (배열과 비슷한 구조의 객체)

5. 내부함수
	함수 속 함수로, 같은 이름의 함수가 동일 선상에 있으면 충돌이 발생할 수 있어서 함수 속에서 활용하는 함수.

6. 콜백함수 
	함수의 매개변수 값으로 함수를 받아서 활용하는 함수

7. 클로저함수
	리턴된 함수(?). 함수의 결과값으로 다른 함수를 return하면 
	예를 들어, test => return fun(), 이면, test()() 형태로 함수를 쓸 수 있다.

8. 내장함수
	8-1.	타이머 함수 : 1초마다 실행을 반복하는 함수, 00초가 지난 후 함수를 수행하는 함수...
		※	setTimeout(function, millisecond) ; 일정시간 후 함수를 한번 실행
		※	setInterval(function, millisecond) ; 일정시간마다 함수를 반복해서 실행
		※	clearTimeout(id) ; setTimeout 중지
		※	clearInterval(id); setInterval 중지
	=> setInterval 은 정지할 방법이 없음!(clear를 바로 쓰면 즉시 정지) => setTimeout(()=>{clearInterval(id)}, 원하는 밀리세컨드) 를 통해 정지시키기
