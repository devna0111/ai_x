ch10 문서객체모델
document. 여러 메소드

1. 텍스트 노드가 필요한 태그 추가하기 : append 메소드 이용하기
	문서객체추가방법 1 : 1) h1태그 생성 2) textNode 생성 3) textNode를 h1에 연결 4) h1을 바디에 연결
2. 텍스트 노드가 필요없는 태그 추가하기
	문서객체추가방법 2 : 1)img태그 생성 2)img태그 속성변경 3)img를 body에 연결
**예시
    <script>
        window.onload = ()=>{
            var h1 = document.createElement('h1'); 
            var textNode = document.createTextNode('추가함');
            h1.appendChild(textNode);
            document.body.appendChild(h1);
        };
    </script>
