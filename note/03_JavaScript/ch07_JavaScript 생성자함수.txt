ch07_JavaScript 생성자함수

1. 생성자함수는 파이썬 class의 생성자함수 __init__과 동일한 형태로 작성..
	function Student( self를 제외한 필요 매개변수 ){
		this.매개변수 = 매개변수 ;
		this.함수이름 = function( ){ 메소드 추가 방법 } ;
	}
	st = new Student( 필요 매개변수 기입 ); => 인스턴스 생성
	
	객체생성함수에서 return 으로 객체를 반환하던 걸 그저 new Class() 형태로 반환하는 차이임.
	
	=> 그런데 위 방법으로 작성하면 모든 객체마다 함수가 단일로 적용하면서 메모리 낭비가 발생함.
		이를 해결하기 위한 방안으로  prototype영역에 공통적으로 작동하는 함수를 할당함.

2. prototype영역
	=> 생성자함수명.prototype.함수명 = function(){} ; => 공통영역에 필요한 함수를 만들 수 있음
	=> 여기서 화살표 함수 작동 안함!

3. 위 내용은 class로도 가능한데,
class 클래스명{
	constructor( 필요인자 ){ // 파이썬의 __init__()역할
		};
	메소드명() { this를 활용한 기능};  클래스명.prototype.함수명() = function(){} 과 동일;
	메소드명 = functiond(){} ; //=> 메소드명() 으로 바로 하지 않으면 각 객체별 메소드로 생성되어서 메모리 낭비
}

A = new 클래스명() ; => 인스턴스 생성
