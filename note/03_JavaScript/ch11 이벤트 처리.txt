1. 인라인 이벤트 모델 : <div onclick="작동할 함수명">으로 작성하고 함수를 script 속 window.onload = function(){}에 정의해두기

2. 기본 이벤트 모델 : <div id='header'> 로 정의하고 
window.onload = ()=>{ var header = document.getElementById('header') ; header.onclick = finction(){} } 로 이벤트 속성에 부여하기

3. 표준 이벤트 모델  : <h1 id="header">로  정의하고
window.onload = ()=>{var h1 = document.getElementById('header'); h1.addEventListener('click', function(){ 작동할 내용 }); } 으로 기능만 부여하기

8. 클릭했을 때 좌표 따기 : window.onclick = ()=>{ let x = event.offsetX; let y = event.offsetY; } // offsetX, Y는 브라우저의 좌표를 number 형태로 반환.
	=> 절대좌표로 이미지 지정 후 img.style.left = event.offsetX + 'px' ; img.style.top = event.offsetY 로 이동시키면서 사용이 가능하다.
