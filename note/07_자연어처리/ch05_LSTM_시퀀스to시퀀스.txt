Seq2Seq

Seq2Seq 모델은 크게 두 개의 모듈, 바로 **인코더(Encoder)**와 **디코더(Decoder)**로 구성
=> 학습 시 인코더 입력 + 디코더 입력 = 디코더 출력 으로 학습
# 디코더 입력은 "S" + 단어 형태로 
# 디코더 출력은 단어 + "E" 형태로
# predict 시에는 입력은 단어로, 디코더 입력값에는 "PP"를 사용함

1. 인코더 (Encoder)의 흐름
인코더는 입력 시퀀스(예: 번역할 문장)를 받아서 그 안에 담긴 모든 정보를 꾹꾹 압축하는 역할

입력 받기: 인코더는 입력 문장의 단어들을 하나씩 순서대로 입력받아. 마치 우리가 문장을 읽듯
정보 압축: 입력받은 모든 단어들의 정보를 하나의 고정된 크기의 벡터로 압축. 이 벡터를 보통 컨텍스트 벡터(Context Vector) 또는 **사고 벡터(Thought Vector)**라고 부르는데, 입력 시퀀스의 모든 의미가 이 작은 벡터 안에 담겨있다고 생각! 

2. 디코더 (Decoder)의 흐름
디코더는 인코더가 압축해 놓은 컨텍스트 벡터를 받아서, 그걸 바탕으로 새로운 출력 시퀀스를 만들어내는 역할

컨텍스트 벡터 받기: 디코더는 인코더가 넘겨준 컨텍스트 벡터를 초기 상태로 받아. 이제 이 벡터가 디코더의 '생각의 씨앗'
출력 시작: 보통 <sos> (start of sequence)라는 특별한 시작 심볼을 입력으로 받아서 첫 번째 단어를 예측하기 시작
순차적 예측: 디코더는 한 번에 하나의 단어씩 예측. 이때 중요한 건, 이전 시점에서 디코더가 예측한 단어가 다음 시점의 입력값으로 들어간다는 것

 마치 우리가 문장을 쓸 때, 방금 쓴 단어를 보고 다음 단어를 떠올리듯
종료: 이렇게 단어를 하나씩 예측하다가 <eos> (end of sequence)라는 특별한 종료 심볼을 예측하면, 출력 시퀀스 생성을 멈춤

📚 훈련과 테스트는 조금 달라! (교사 강요)
Seq2Seq 모델을 훈련시킬 때는 **교사 강요(Teacher Forcing)**라는 방법을 사용

훈련할 때: 디코더가 다음 단어를 예측할 때, 자기 자신이 예측한 단어가 아니라 실제 정답 단어를 입력으로. 이렇게 하면 모델이 잘못된 방향으로 학습되는 걸 막고, 더 안정적으로 배울 수 있음. 마치 선생님이 정답을 알려주면서 공부시키는 것
실제로 사용할 때 (테스트): 이때는 선생님이 없으니까, 디코더는 오직 인코더가 준 컨텍스트 벡터와 자기가 방금 예측한 단어만을 가지고 다음 단어를 예측. <eos>가 나올 때까지 계속!
