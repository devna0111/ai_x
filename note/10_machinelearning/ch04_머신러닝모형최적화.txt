Feature 선택
	다중공선성이 높으면 회귀계수 해석이 어려워짐
	=> 다중공선성을 낮추는 새로운 변수를 만드는 과정 => 주성분 분석

	변수 선택 1. 현재 가지고 있는 변수 중에서 괜찮은 변수를 뽑는 방법 SelectKBest
	변수 선택 2. 현재 가지고 있는 변수들로 조합을 통해 상관관계가 없는 새로운 변수로 만드는 방법

	주성분 분석 PCA : 비지도학습. 독립변수들로 상관관계가 없는 새로운 변수를 조합
	pca = PCA().fit_transform(iris_X)
	pca.components_ 속에 계산에 필요한 가중치가 담김
		=> 개수를 줄이면 accuracy가 떨어질 수 있음, 설명력의 저하 => 설명 분산의 비율이 떨어짐
	: 회귀분석에서 결과가 원하는 값이 나오지 않으면 사용하기도 하며
	: 보통 이미지 분석에서 압축, 노이즈 제거용으로 활용한다.

	# 상관계수 확인

	# feature_importance_ 의 cumsum을 사용해서 feature를 선택
	# 이에 따라 feature를 뽑을 때는 RFE 객체를 사용하거나 그냥 뽑아도 무방

	# SelectKBest 도 나쁘지 않음. 좋은 feature를 찾아서 추출해줌.  그러나 뭐가 좋고 나쁜 지 체크는 반드시 필요.

## 최적모형탐색 => 앙상블 모형
목적 : 여러 분류모형을 하나의 메타 분류 모델로 연결하여 개별 모형보다 더 좋은 일반화 성능을 달성
방법 :
	하나의 메타 분류 알고리즘 이용 : 배깅(bagging), 부스팅(boosting)
	여러 분류 알고리즘을 이용 : 다수결 투표
배깅 vs 부스팅
	배깅 : => 메타 모델 : 여러 의사결정트리에서 데이터를 복원추출로(데이터중복가능!) 
			선정한 데이터를 가져와서 feature를 선정한 만큼 사용해서 여러 예시 모델들 병렬로 학습 
			-> 모델 별 결과에 따라 점수를 가감해서 가장 점수가 높은 모델로 predict.
		복원 추출로 데이터를 선별해 병렬학습 후 score가 높은모델에 가중치 부여
		과적합을 줄일 수 있음.
		데이터가 충분할 때 과적합을 방지하면서 안정적인 모델이 필요할 때
		대표적으로 RandomForestClassifier, BaggingClassifier
	부스팅 : => 배깅과 다르게 병렬처리 하지 않음. 여러 모델에서 틀린 모델만 학습을 함
		순차적으로 모델 학습. 앞의 모델에서 틀린 데이터의 50%를 다음 모델에서 재학습
		가중치를 오답에 둠 : 오답에 집중
		성능 극대화
		성능 극대화해야 하는데 데이터가 비교적 부족하거나 복잡한 패턴의 학습을 해야할 경우
		=> 대표적으로 LightGBM, XGBoost
		=> CatBoost는 Recall이 좋아 생명과 직결되는, 재현율이 필요한 부분에서 사용함
다수결 투표 => 여러 모델의 결과값에 따라 그래서 예측값이 뭔 지 투표하는..
