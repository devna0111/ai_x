** 세션 : requsets 속 Session()객체, 브라우저에서 어떤 ip주소의 쿠키가 접속을 하면 서버가 세션을 생성.
		=> 특정 세션 ID를 통해 사용자를 식별하고 각기 다른 화면 출력
		=> 쿠키는 음식점 번호표, 세션은 음식점이 인식하는 방법

** requests # http 요청 처리 lib
** from requests_file import FileAdapter # 컴퓨터 내 파일 탐색기
s = requests.Session() # http 요청 관리를 위한 세션 객체
s.mount('file://', FileAdapter())  => (방식, 적용할 것 형태)
response = s.get('file:// 파일 주소(C,D드라이브 제외))
response.status_code => 현재 서버 상태 체크 가능
response.text => 내부 내용 확인 가능
=> 위 내용을 html 형태로 parsing 하려면
from bs4 import BeautifulSoup
soup = BeautifulSoup(response.text, "html.parser') # parsing을 위한 BeautifulSoup객체 생성
# 첫 매개변수는 parsing을 위한 내용, 두번째 매개변수는 어떤 형식의 파일을 parsing 할지

# BeautifulSoup 객체의 메서드 (선택자는 혼합선택자가 사용이 가능하다!)
	1. .select_one(선택자) => 단일 객체 반환, .attrs 속성체크 .text 내용물 체크, .name 태그이름 체크
	2. .select(선택자) => 1번 사항의 단일객체들을 리스트로 반환
		=> select는 원하는 선택자를 단일 스트링 속에 모두 포함시켜서 가져올 수 있음.
			ex) soup.select('h1.css, span')
	3. .find(태그, 속성) 속성은 { '속성종류' : '속성이름' } 로 기입.
	3. .find_all(태그, 속성) => 만약에 속성이 같다면,
		find_all(['h1', 'span'], {'class': 'css'}) 형태로 모두 가져올 수 있음.
=> 없는 엘리먼트를 찾으면 리스트를 반환하는 경우 빈리스트로.
	단일 객체를 반환하는 경우 None 반환
