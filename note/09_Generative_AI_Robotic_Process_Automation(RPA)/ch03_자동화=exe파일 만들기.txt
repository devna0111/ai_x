ch03_자동화=>exe파일 만들기

py 파일을 실행파일로 만들기 : pyinstaller --onefile 2-2_naver_report.py
위 코드를 실행하면 dist폴더에 exe 파일. 이 파일을 root로 옮겨 파일 명을 원하는 데로 수정
("genai_rpa.exe")

이후 batch 파일이 필요(file_name.bat)
내용
@echo off                :: 명령어 실행 시 화면에 명령 표시하지 않음
pushd "%~dp0"            :: 작업 폴더를 배치파일 위치로 이동
genai_rpa.exe            :: genai_rpa.exe 파일 실행
pause                    :: 창이 바로 닫히지 않도록 일시정지

=> windows scheduler를 통해 백그라운에서 진행하게
